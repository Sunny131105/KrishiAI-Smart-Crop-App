KrishiAI is an intelligent, machine-learning-powered web application designed to help farmers and agricultural planners make data-driven crop decisions. Built using Streamlit and scikit-learn, the system analyzes soil nutrients, weather conditions, and regional data to recommend the most suitable and profitable crop.

👉 Live Demo: https://krishiai-smart-crop-app-btxjip4498rfbxbqnjw65r.streamlit.app/ 



## 📌 Problem Statement

Farmers often rely on traditional methods or intuition to decide which crop to cultivate, which may lead to low productivity or financial loss. KrishiAI addresses this challenge by leveraging machine learning and historical agricultural data to provide reliable crop recommendations and profitability insights.



## 🚀 Features

✨ **Interactive UI**  
Built with Streamlit — enter parameters and view results in real time.

🌱 **Crop Recommendation System**  
Generate crop suitability recommendations based on soil and environmental data.

🔍 **Data-Driven Logic**  
Under the hood, model or rule-based prediction helps align recommendations with practical agronomy.

📈 **Easy to Deploy**  
Can be deployed on platforms like Streamlit Cloud with a single command.




## 🧠 How It Works

1. **User Inputs**  
   Users enter or upload information such as:
   - Soil parameters (e.g., pH, nutrients)
   - Temperature and humidity
   - Rainfall and seasonal conditions

2. **Prediction Logic**  
   The app applies helper functions and prediction logic to analyze inputs and suggest suitable crops.

3. **Output**  
   Results are displayed interactively, guiding users on which crops are best suited for their farm conditions.
